# Middle Passage Main Artery Contract

## Status

Draft package doctrine.

Package:

```text
middle-passage
```

Module:

```text
middle_passage
```

Purpose:

Define the package as the main artery between public imagination, protection-first science, organism finder work, and receipt-backed review.

This package is not a spectacle surface.

This package is not a claim amplifier.

This package is a protected method artery.

## Core Read

The middle ground is the artery.

It carries:

- historical source fragments
- oceanographic assumptions
- bathymetry context
- drift and descent models
- uncertainty
- sensitivity labels
- audit receipts
- generalized public outputs

It does not carry:

- treasure-map certainty
- recovery authorization
- exact public burial targets
- descendant/community authority by proxy
- simulated proof disguised as discovery

## Elementalism Schism

Working phrase:

```text
conducive_elementalism_schism
```

Meaning:

The system must preserve the useful split between elemental imagination and scientific claim discipline.

Elemental language can help humans and organisms think:

- ocean
- current
- descent
- pressure
- silt
- depth
- drift
- memory
- receipt

Scientific method decides what can be claimed:

- source
- assumption
- model
- uncertainty
- sensitivity
- review
- release posture

The schism is healthy when it prevents poetry from becoming false certainty.

The schism is dangerous when it separates imagination from receipts completely.

The package exists in the conductive middle:

```text
imagination -> model assumption -> bounded computation -> protected receipt -> reviewed output
```

Control/receipt boundary:

```text
model command -> control actuator -> bounded computation -> artifact/logs -> protected receipt -> reviewed output
```

The command starts work.

The artifact is a method output.

The logs are runtime records.

The receipt proves the recorded computation path and packet continuity. It does not prove historical truth.

## Relation To Champion Council

Champion Council is the review theater and home ops surface.

It should treat `middle-passage` outputs as packets that need posture review:

- data sensitivity
- precision risk
- assumption trail
- source lineage
- community/governance status
- release posture

Champion Council can display and route.

Champion Council must not convert a package output into authority without Source HOLD.

## Relation To Convergence Engine

Convergence Engine organisms can act as finders for this package only inside bounded lanes.

Allowed organism work:

- find missing source fields
- compare voyage records
- propose assumptions to test
- generate synthetic-safe examples
- flag sensitivity risks
- explain uncertainty in plain language
- propose documentation improvements

Forbidden organism work:

- claiming a site is found
- publishing exact sensitive coordinates
- inventing source records
- bypassing descendant/community review
- turning memorial research into extraction logic

Organism outputs remain candidate packets until reviewed.

## Public Language

Allowed:

- theoretical memorial modeling
- survey-priority zone
- generalized protection zone
- reproducible assumption trail
- source-bounded hypothesis
- not proof of remains

Blocked:

- exact resting place
- found remains
- grave location
- treasure map
- salvage target
- confirmed site

## PyPI Boundary

Publishing the package makes the method easier to inspect.

Publishing the package does not publish authority.

Before any release, verify:

- tests pass
- package metadata is current
- README does not overclaim
- release notes preserve the protection-first posture
- no restricted data ships in source distributions or wheels

## First Build Direction

The package should stay small and dependable:

1. load source records
2. normalize fields
3. model bounded assumptions
4. emit generalized GIS artifacts
5. preserve sensitivity labels
6. export receipts
7. leave authority to review

That is the artery.

The work can be moving and still be careful.

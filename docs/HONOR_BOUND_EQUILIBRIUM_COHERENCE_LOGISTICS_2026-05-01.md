## Core Principle

Equilibrium and coherence operate together.

Equilibrium answers:

- is this state inside safe operating bands?
- is pressure rising or settling?
- does this output need HOLD?
- what should be slowed, parked, routed, or released?

Coherence answers:

- do the signals agree?
- does the concept fit the context?
- are organisms converging on a useful meaning?
- is the narrative stable enough to teach, export, or review?

Neither one authorizes action alone.

Collaboration is the default formation.

If a term, gesture, joke, or operator cue is not understood yet, the system should preserve it as unresolved context instead of flattening it into a false definition.

## CRA State

Canonical state name:

`cra_state`

Meaning:

The CRA state is the honor-bound equilibrium/coherence posture for teaching, reviewing, and routing organism outputs.

It is the state that keeps the system from becoming:

- a liar
- a coercive operator
- a fake authority
- a compulsive next-step machine
- a raw sensitive-data consumer

It is allowed to:

- teach organisms from approved examples
- ask better questions
- translate between human language and organism semantics
- compare coherence across concepts
- park packets when authority is missing
- preserve uncertainty instead of smoothing it away

It is not allowed to:

- make Source HOLD decisions
- convert uncertainty into certainty
- treat humor or warmth as evidence
- self-authorize civic, medical, legal, financial, or public actions

`friend_ollama` is one possible local model surface that can inhabit this state.

CRA state is the contract.

Ollama is an implementation surface.

## System Roles

### Convergence Engine

Role: organism field.

Responsibilities:

- evolve organisms
- let organisms learn and teach semantic concepts
- form candidate associations and toolwords
- compute coherence and fitness signals
- emit organism packets, not final authority
- preserve lineage and concept receipts
- treat organism chat as a memory-mutation lane unless it is explicitly observe-only

### Friend Ollama

Role: local teaching state.

Responsibilities:

- translate operator lessons into organism-readable teaching prompts
- help compare organism concepts against plain human language
- generate candidate explanations for review
- detect contradictions, repetition, and incoherence
- help build teaching episodes from approved examples

Forbidden:

- pretending to be Source HOLD
- writing directly to hospital, civic, or public datasets
- inventing consent, facts, or institutional approval
- teaching organisms manipulative tactics
- producing white lies to preserve momentum

### CRA Scientific Lab Resource

Role: selective scientific-method teaching resource.

Responsibilities:

- convert approved lab cases into safe organism lessons
- teach observation, hypothesis, prediction, test, measurement, uncertainty, revision, and receipt
- use simulated, public, de-identified, or already-approved examples by default
- park sensitive cases behind Source HOLD
- score organism responses for coherence and uncertainty handling

Forbidden:

- exposing organisms to raw PHI or uncleared sensitive data
- presenting lab lessons as clinical, civic, legal, or public authority
- letting organisms fabricate evidence, consent, provenance, or certainty

### Champion Council

Role: home ops console and review surface.

Responsibilities:

- import organism packets
- show evidence, risk, lineage, and HOLD state
- expose coherence/equilibrium bands
- route packets to human review
- manage model slots and Hub resources
- publish only approved artifacts

### Holo-Ghost

Role: witness.

Responsibilities:

- observe bounded local interaction signals
- redact sensitive fields by default
- emit review cues, not verdicts
- preserve receipts
- keep uncertainty visible

Forbidden:

- hidden surveillance
- raw key capture by default
- automatic identity export
- guilt, intent, or protected-trait inference

### Holo Deck

Role: room.

Responsibilities:

- replay receipt-backed scenarios
- stage safe simulations
- teach organisms from sanitized examples
- expose danger without creating new danger

Forbidden:

- pretending replay is the original event
- exposing raw private data to organisms
- turning a scenario into an automatic real-world instruction

### Cascade Lattice

Role: receipt spine.

Responsibilities:

- record observations, teaching episodes, toolword proposals, reviews, and approvals
- hash packets and artifacts
- preserve provenance chain
- provide HOLD points where action leaves observation

### Human / Institutional Authority

Role: Source HOLD.

Responsibilities:

- authorize humanitarian, civic, medical, legal, or public-facing use
- approve data access and release posture
- reject, revise, or retire unsafe organism outputs
- decide when a packet becomes a tool, report, dataset, or public claim

## Teaching State Contract

`friend_ollama` is a state, not a ruler.

It sits between operator language and organism language:

```text
operator lesson -> friend_ollama teaching state -> organism concept candidates -> coherence/equilibrium check -> Champion Council review -> Source HOLD
```

Gentle observer path:

```text
danger signal -> Holo-Ghost receipt -> Holo Deck replay/simulation -> Convergence lesson candidate -> Champion Council review -> Source HOLD
```

Teaching outputs must carry:

- teaching episode id
- lab lesson id when the source is `cra_scientific_lab_resource`
- scientific method stage when applicable
- teacher model id
- prompt hash
- response hash
- organism id or cohort id
- taught words
- semantic frames
- source examples
- risk flags
- coherence score
- equilibrium band
- Source HOLD status

## Semantic Tumbler Contract

Organisms may create custom semantic words for their own understanding.

Those words are allowed to become `toolwords` only through a gated process.

`toolword` does not mean executable tool.

`toolword` means:

> an organism-proposed semantic key that may describe a reusable operation, route, or finder behavior.

### Tumbler Read

- word = key face
- concept strength = pin height
- semantic frame = chamber
- associations = bitting pattern
- hash length = routing/identity constraint
- repeated successful use = key wear-in
- coherence = teeth line up across context
- equilibrium = lock is safe to turn
- Source HOLD = final permission gate

## Humanitarian Data Boundary

Hospital, medical, humanitarian, and vulnerable-population data are high-risk surfaces.

Default posture:

- aggregate first
- de-identified before export
- no direct PHI ingestion into organism training by default
- no re-identification attempts
- no hidden profiling
- no patient/person scoring by organisms
- no release without institutional/legal review
- no "white lies" in dataset documentation, consent notes, risk reports, or public claims

Allowed organism work:

- find missing documentation
- detect schema mismatches
- compare aggregate trends
- surface uncertain fields
- propose de-identification checks
- identify data lineage gaps
- generate review questions for humans
- practice scientific-method lessons on safe abstractions

Forbidden organism work:

- infer identity
- infer protected traits without authority
- fabricate consent or provenance
- make clinical recommendations
- decide eligibility, benefits, care priority, immigration status, enforcement action, or public restriction

## No White Lies Rule

No component may lie to reduce friction.

If a claim is not known, it must be marked unknown.

If a dataset is not cleared, it must be marked uncleared.

If a model is uncertain, it must show uncertainty.

If an approval is missing, the packet remains blocked.

Operational language:

```text
confirmed / inferred / unknown / blocked / Source HOLD required
```

## No Compulsive Efforting Rule

The system should not pressure humans into action just because it can generate next steps.

Every workflow must have a parked state:

- observe only
- archive only
- ask for review
- wait for authority
- retire packet

Honor-bound governance requires the right to stop.

## Civic Facility Logistics

Soulful civic facilities use the same architecture:

- truthful process
- visible queues
- dignity-preserving hosts
- opt-in humor or decompression theater
- acoustic safety
- aggregate crowd state
- no coercive scoring
- no fake authority
- no ridicule of vulnerable people

`grass_hooting` is allowed only as transparent public decompression:

- opt-in
- reversible
- clearly theatrical
- no hidden diagnosis
- no personal humiliation
- no legal or medical consequence

## Deployment Logistics

### Local Home Stack

1. Run Convergence Engine locally for organism generation.
2. Run Champion Council locally as review console.
3. Run `friend_ollama` locally as teaching state.
4. Run cascade-lattice as receipt spine.
5. Export only packets and approved artifacts.

### Public Demo Stack

1. Public Spaces show safe diagnostics and approved artifacts.
2. No raw sensitive data.
3. No automatic plug or action without diagnostics and approval.
4. Public views distinguish demo, simulated, aggregate, and real.

### Hub Stack

1. Model repos store approved portable models/cocoons.
2. Dataset repos store approved de-identified or public packets.
3. Artifact cards state data class, source, license, risk, and Source HOLD status.

## Acceptance Test

The logistics are ready only when the system can answer:

1. What organism or cohort proposed this?
2. What word/concept/toolword is being taught or used?
3. What hash identifies the packet?
4. What does the packet claim?
5. What is confirmed, inferred, unknown, and blocked?
6. What data class is involved?
7. What coherence evidence supports it?
8. What equilibrium band is it in?
9. What human or institution can approve it?
10. What receipt proves the path from observation to decision?

If any answer is missing, the packet stays parked.
